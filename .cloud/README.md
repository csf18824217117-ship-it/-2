# 云环境配置备份

此目录保存了已经在当前云环境中执行验证的安装脚本和启动说明。

- `install.sh`：安装锁定依赖并执行生产构建。
- `start.md`：服务启动和浏览器就绪检查。
- `environment-config.json`：提交给环境配置工具的完整更新内容；仅包含 `install_script` 和 `start_skill`，不包含凭据。

应用代码已推送到 `main`。保存云环境草稿时，配置工具返回 `stale_base`：草稿创建后环境配置已被发布或改变，旧对话不能继续保存。

请从当前环境设置打开新的设置对话，并让助手读取当前草稿，再与 `environment-config.json` 核对后保存。不要直接覆盖新草稿中的其他设置。保存草稿后仍需在环境设置中审阅并发布；本文件不代表配置已经保存或发布，也不代表网站已部署。

这些文件已提交到仓库，可下载并交给新的设置对话，不依赖本次工作区。
